## 5. 考虑以下两个事务：

T34:
read(A);
read(B);
if A = 0 then B := B + 1;
write(B).

T35:
read(B);
read(A);
if B = 0 then A := A + 1;
write(A).

为两个事务添加锁定（lock）和解锁（unlock）的指令，使事务 T34 和 T35 遵循两阶段锁协议(Two-PhaseLocking Protocol)。说明这样会不会导致死锁。
