1. 事务控制 (Transaction Control)

设置隔离级别：
sql
SET TRANSACTION ISOLATION LEVEL [LEVEL_NAME];

报告中使用了 REPEATABLE READ。
开启事务：
sql
BEGIN TRAN; -- 或 BEGIN TRANSACTION;

提交事务：
sql
COMMIT TRAN; -- 或 COMMIT TRANSACTION;

回滚事务：
sql
ROLLBACK TRAN; -- 或 ROLLBACK TRANSACTION;

2. 数据操作 (DML - Data Manipulation Language)

更新数据：
sql
UPDATE table_name
SET column = value
WHERE condition;

示例：UPDATE students SET grade = 1993 WHERE sid = '800001216';

查询数据：
sql
SELECT FROM table_name WHERE condition;

示例：SELECT FROM students WHERE sid = '800001216';
插入数据：
sql
INSERT INTO table_name (col1, col2, ...)
VALUES (val1, val2, ...);

示例：INSERT INTO teachers (...) VALUES (...);

3. 错误处理 (Error Handling)

使用 TRY...CATCH 结构来捕获和处理运行时错误（如死锁、锁超时）。

基本结构：
sql
BEGIN TRY
-- 可能出错的SQL代码
END TRY
BEGIN CATCH
-- 错误处理逻辑
END CATCH

关键函数：
ERROR_NUMBER(): 获取错误号（如 1205 代表死锁，1222 代表锁超时）。
ERROR_MESSAGE(): 获取完整的错误信息文本。
抛出异常：
sql
THROW; -- 重新抛出当前捕获的异常

4. 系统配置与诊断 (System Configuration & Diagnostics)

用于配置会话行为和查看系统状态。

设置锁超时：
sql
SET LOCK_TIMEOUT timeout_period_in_milliseconds;

示例：SET LOCK_TIMEOUT 2000; （2秒超时）
查看进程/阻塞信息：
sql
EXEC sp_who; -- 查看当前所有用户和内部进程

通过 status (如 suspended) 和 blk (阻塞者SPID) 列诊断阻塞问题。
引入延迟：
sql
WAITFOR DELAY 'hh:mm:ss'; -- 暂停执行指定时间
